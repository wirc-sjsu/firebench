# Package Contents

FireBench evolves quickly, so this page points to maintained reference material instead of
duplicating a manual inventory of modules, models, datasets, and functions.

- [API Reference](api/index.rst) documents public Python modules and functions.
- [CLI Reference](reference/cli.md) summarizes the installed command-line entry points.
- [Models Used in FireBench](fire_models_info/index.md) describes bundled fuel and rate-of-spread
  models.
- [Datasets and Fire Experiments](dataset_experiments/index.md) describes reusable validation data.
- [Benchmark Specifications](benchmarks/index.md) defines benchmark cases, KPIs, and scoring groups.
- [Standard Namespace](namespace.md) lists standardized model-output variable names.

The source tree under `src/firebench/` remains authoritative for internal and experimental modules
that are not part of the documented public API.
