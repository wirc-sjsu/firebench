API Reference
=============

API stability
-------------

Objects imported by a package ``__init__`` and documented here are the supported public surface
unless their docstring says otherwise. Configuration loaders, dataclasses, and newly introduced
plotting or signing helpers are experimental in the 0.10 development series. Underscore-prefixed
objects and modules omitted from this reference are internal and may change without deprecation.
